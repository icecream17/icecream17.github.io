Theorem mul3sum4d 51297
Description: If 𝑀 = (𝐶 + 𝐷) and 𝐴 = (3 · 𝐶), then (3 · 𝐷) and (𝑀 + 𝐴) sum to four times 𝑀. (Contributed by Zhi Wang, 17-Oct-2026.)
Hypotheses
Ref Expression
mul3sum4d.1 ⊢ (𝜑 → 𝐶 ∈ ℂ)
mul3sum4d.2 ⊢ (𝜑 → 𝐷 ∈ ℂ)
mul3sum4d.3 ⊢ (𝜑 → 𝑀 = (𝐶 + 𝐷))
mul3sum4d.4 ⊢ (𝜑 → 𝐴 = (3 · 𝐶))
Assertion
Ref Expression
mul3sum4d ⊢ (𝜑 → (4 · 𝑀) = ((3 · 𝐷) + (𝑀 + 𝐴)))
