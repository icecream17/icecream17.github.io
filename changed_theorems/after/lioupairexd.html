Theorem lioupairexd 51489
Description: Explicit positive-integer summands with prescribed common value under Liouville's function give the corresponding existence statement. (Contributed by Zhi Wang, 17-Oct-2026.)
Hypotheses
Ref Expression
lioupairexd.1 ⊢ (𝜑 → 𝐴 ∈ ℕ)
lioupairexd.2 ⊢ (𝜑 → 𝐵 ∈ ℕ)
lioupairexd.3 ⊢ (𝜑 → 𝑁 = (𝐴 + 𝐵))
lioupairexd.4 ⊢ (𝜑 → (λ‘𝐴) = 𝑆)
lioupairexd.5 ⊢ (𝜑 → (λ‘𝐵) = 𝑆)
Assertion
Ref Expression
lioupairexd ⊢ (𝜑 → ∃𝑎 ∈ ℕ ∃𝑏 ∈ ℕ (𝑁 = (𝑎 + 𝑏) ∧ (λ‘𝑎) = 𝑆 ∧ (λ‘𝑏) = 𝑆))
Distinct variable groups:   𝐴,𝑎,𝑏   𝐵,𝑏   𝑁,𝑎,𝑏   𝑆,𝑎,𝑏
Allowed substitution hints:   𝜑(𝑎, 𝑏)   𝐵(𝑎)
