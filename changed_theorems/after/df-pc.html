Definition df-pc 17064
Description: Define the prime count function, which for a nonzero integer returns the largest exponent of a given prime that divides the integer. For a nonzero rational number, it returns the exponent of the prime in the numerator minus its exponent in the denominator; see pcdiv 17079. Its value at zero is +∞; see pc0 17081. (Contributed by Mario Carneiro, 23-Feb-2014.)
Assertion
Ref Expression
df-pc ⊢ pCnt = (𝑝 ∈ ℙ, 𝑟 ∈ ℚ ↦ if(𝑟 = 0, +∞, (℩𝑧∃𝑥 ∈ ℤ ∃𝑦 ∈ ℕ (𝑟 = (𝑥 / 𝑦) ∧ 𝑧 = (sup({𝑛 ∈ ℕ0 ∣ (𝑝↑𝑛) ∥ 𝑥}, ℝ, < ) − sup({𝑛 ∈ ℕ0 ∣ (𝑝↑𝑛) ∥ 𝑦}, ℝ, < ))))))
