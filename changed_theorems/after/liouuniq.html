Theorem liouuniq 51482
Description: Characterize Liouville's function by complex-valued complete multiplicativity on rationals, value minus one on primes, and value one at minus one. The first conditions determine the values on positive integers; the last fixes the sign on negative inputs. The counterexample lioununiq 51481 shows why the last condition is needed. For an alternate version using the evaluation formula on dom Ω, see liouuniq2 51483. (Contributed by Zhi Wang, 27-Oct-2026.)
