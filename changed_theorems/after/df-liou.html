Definition df-liou 51419
Description: Define Liouville's function on the rationals, extending its positive-integer definition and assigning value zero at zero. On nonzero inputs its value is minus one raised to the value of the signed prime Omega function; see liouval 51423.

The name "Liouville's function" is used both for this rational extension and for its positive-integer restriction. Domain qualifiers are included when a comparison needs the distinction.

For positive integers, Liouville's function has value one when the number of prime factors counted with multiplicity is even, and minus one when it is odd; see lioueq1 51437 and lioueqm1 51438 for the corresponding criteria on nonzero rationals. See T. M. Apostol, "Introduction to Analytic Number Theory" (1976), section 2.12, p. 37, https://doi.org/10.1007/978-1-4757-5579-4 51438.

Hajdu and Hajdu, "On the Liouville function on rational polynomial values" (2021), section 1, https://doi.org/10.4064/aa200706-31-5 51438, extend the positive-integer function to positive rationals by (λ‘(𝑛 / 𝑘)) = ((λ‘𝑛) / (λ‘𝑘)) for 𝑛, 𝑘 ∈ ℕ. To obtain the formula used here, observe that the prime valuations in df-bom 51381 subtract denominator multiplicities, so (Ω‘(𝑛 / 𝑘)) = ((Ω‘𝑛) − (Ω‘𝑘)) by bomdiv 51392. Consequently, the quotient of the two positive-integer values of Liouville's function is (( -1↑(Ω‘𝑛)) / ( -1↑(Ω‘𝑘))) = ( -1↑((Ω‘𝑛) − (Ω‘𝑘))) = ( -1↑(Ω‘(𝑛 / 𝑘))). Common factors cancel in the difference, so the fraction need not be reduced. The product version is lioudiv 51460; the nonzero values have square one by liouvalsq 51439.

Immediately before Theorem 2.4, the same paper extends the function to negative rationals by (λ‘𝑥) = (λ‘( -𝑥)). The signed prime Omega values are unchanged by negating a nonzero rational (bomneg 51398), so the same exponential formula gives this convention too; see liouneg 51466.

The value at zero is a separate convention, following Helfgott's choice for integer inputs in "The parity problem for reducible cubic forms" (2006), introduction after equation (1.1), https://arxiv.org/abs/math/0408142 51466. Since Ω is defined only on nonzero rationals, the explicit zero branch extends the function to all of ℚ. Complete multiplicativity on rationals is lioumul 51448; liouuniq2 51483 shows how it determines the value at zero once the nonzero evaluations are fixed.

The function defined here differs from the "Liouville function of the first kind" proposed by A. Vieru in section 7, p. 22 of arXiv:1306.0496v4 (2015 revision of the 2013 preprint), https://arxiv.org/pdf/1306.0496v4#page=22 51483. His equal-count clause assigns to a fraction the negative of Liouville's function at its denominator. Thus it gives minus one at (4 / 9): both integer prime-factor counts are two, and the value of Liouville's function at nine is one. The defining formula here gives one at that fraction, since its signed prime Omega value is zero. The two prescriptions therefore disagree where that proposal gives an explicit rule. On p. 23 the same source proposes a second kind: value one when the two prime-factor counts differ by one, and minus one when they are equal. This also gives minus one at (4 / 9). The following note leaves larger count differences undecided. Neither partial prescription is adopted as a complete rational extension. The first prescription also needs a convention for choosing the fraction's numerator and denominator: without one, the equal fractions one over one and two over two receive opposite values.

A different completely multiplicative rational extension of the positive-integer function is obtained by multiplying by signum; see lioununiq 51481. It is excluded here by the normalization at minus one in liouuniq 51482.

For evaluations at zero, one, and primes see liou0 51424, liou1 51456, and liouprm 51443. The Goldbach applications are liougb4 51605 and liougb 51613. (Contributed by Zhi Wang, 17-Oct-2026.)
