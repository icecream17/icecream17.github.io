Theorem lioumodcld 51519
Description: The value of Liouville's function at a nonzero canonical residue is a sign. (Contributed by Zhi Wang, 17-Oct-2026.)
Hypotheses
Ref Expression
lioumodcld.1 ⊢ (𝜑 → 𝑃 ∈ ℕ)
lioumodcld.2 ⊢ (𝜑 → 𝐴 ∈ ℤ)

Assertion
Ref Expression
lioumodcld ⊢ (𝜑 → (λ‘(𝐴 mod 𝑃)) ∈ { -1, 1})
