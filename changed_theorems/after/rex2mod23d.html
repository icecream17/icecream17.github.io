Theorem rex2mod23d 51368
Description: An explicit pair satisfying the displayed bounds and either of the two congruences supplies a positive integer witness below 𝑄 and a nonzero integer witness of absolute value below 𝑁. Existential introduction for the bounded congruences in mod23exd 51371. (Contributed by Zhi Wang, 20-Oct-2026.)
Hypotheses
Ref Expression
rex2mod23d.1 ⊢ (𝜑 → 𝐾 ∈ ℕ)
rex2mod23d.2 ⊢ (𝜑 → 𝐷 ∈ ℤ)
rex2mod23d.3 ⊢ (𝜑 → ((𝐾 < 𝑄 ∧ (abs‘𝐷) ∈ ℕ ∧ (abs‘𝐷) < 𝑁) ∧ ((((2 · 𝐾) · 𝑁) mod 𝑃) = (𝐷 mod 𝑃) ∨ (((3 · 𝐾) · 𝑁) mod 𝑃) = ((2 · 𝐷) mod 𝑃))))
Assertion
