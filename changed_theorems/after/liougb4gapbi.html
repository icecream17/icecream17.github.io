Theorem liougb4gapbi 51511
Description: Membership in the gap set 𝑆 is equivalent to being a positive integer difference (𝑣 − 𝑢) from a positive-positive pair (𝑢 + 𝑣) = 𝑀. The equality hypothesis specifies this set; the characterization uses fresh summand variables. (Contributed by Zhi Wang, 17-Oct-2026.)
Hypothesis
Ref Expression
liougb4gapbi.1 ⊢ 𝑆 = {𝑡 ∈ ℕ ∣ ∃𝑎 ∈ ℕ ∃𝑏 ∈ ℕ ((𝑀 = (𝑎 + 𝑏) ∧ (λ‘𝑎) = 1 ∧ (λ‘𝑏) = 1) ∧ 𝑡 = (𝑏 − 𝑎))}
Assertion
Ref Expression
liougb4gapbi ⊢ (𝐷 ∈ 𝑆 ↔ (𝐷 ∈ ℕ ∧ ∃𝑢 ∈ ℕ ∃𝑣 ∈ ℕ ((𝑀 = (𝑢 + 𝑣) ∧ (λ‘𝑢) = 1 ∧ (λ‘𝑣) = 1) ∧ 𝐷 = (𝑣 − 𝑢))))
